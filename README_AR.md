# AI Data Intelligence Pro

## التشغيل السهل على Windows
1. فك ضغط ملف ZIP بالكامل.
2. افتح مجلد `AI_Data_Intelligence_Pro`.
3. اضغط مرتين على `run.bat`.
4. انتظر تنزيل المكتبات أول مرة (يتطلب اتصال إنترنت).
5. ستفتح الواجهة في المتصفح. إذا لم تفتح تلقائيًا، افتح `http://localhost:8501`.

## تشغيل يدوي
افتح CMD داخل مجلد المشروع ثم نفّذ:
```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## الصيغ المدعومة
CSV, XLSX, XLS, JSON, Parquet.

## الوظائف
- Data profiling وملخص البيانات.
- تحليل استكشافي ورسوم تفاعلية.
- تنظيف اختياري في نسخة منفصلة.
- AutoML لتجربة نماذج تصنيف أو انحدار ومقارنة النتائج.
- Clustering باستخدام K-Means.
- Anomaly Detection باستخدام Isolation Forest.
- تصدير CSV/Excel/JSON وتقارير جودة.
- إنشاء SQLite وSQL schema.

## ملاحظات
- التطبيق يعمل محليًا على جهازك، والملفات لا تُرسل إلى خدمة ذكاء اصطناعي خارجية.
- AutoML يختبر نماذج تقليدية من scikit-learn، وليس نموذجًا سحريًا يصلح لكل البيانات.
- اختر عمود الهدف المناسب وتحقق من أن الأعمدة لا تحتوي على معلومات تكشف الإجابة بصورة مباشرة (data leakage).
- النتائج الاستكشافية لا تضمن دقة تنبؤ عالية، خاصة مع البيانات الصغيرة أو غير المتوازنة.
- يفضّل Python 3.11 أو 3.12 على Windows لتوافق المكتبات. قد تعمل إصدارات أحدث، لكن بعض المكتبات قد تتأخر في دعمها.
